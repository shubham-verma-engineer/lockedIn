# 6. Security, Access Control, & App Store Safety Manual

## 6.1 Linguistic Constraints & Content Safety Framework

To insulate the dynamic platform from incurring immediate policy rejection flags under **Apple Review Guideline 1.2 (Harassment / User-Generated Safety)** or **Google Play Developer Defamation Guidelines**, all string compilation engines are locked behind severe programmatic sandboxes:

* **Structural Identity Ban:** AI prompts and template matrix arrays are strictly forbidden from targeting an individual's organic appearance, physical metrics, gender identities, racial profiles, or mental capacities.
* **Action Inversion Targets:** All conversational insults, roasting variations, or strict tone expressions must exclusively focus on mutable behavioral choices—specifically personal procrastination, broken execution schedules, text excuses, and screen-time lag.
* **Age Threshold Metrics:** App profile registration config mandates a firm **17+ Age Tier designation** across submission stores.
* **Explicit Consent Gates:** The 18+ Abusive engine option must remain disabled on onboarding. Explicit confirmation popup dialogues must be checked by the user to lift the profile restriction.
