* **Technical Scope Assignment:** Code the core Java timezone transformation middleware layer responsible for converting native physical server UTC moments into user local logical system activity calendar dates, incorporating the fixed 3-hour backward grace variable adjustment.

#### **Rigorous Acceptance Criteria:**
1. An active logging API request incoming at 01:30 AM local time on a Tuesday calendar day must be written into PostgreSQL storage records under a Monday date identifier.

3. The native calendar logic parser must cleanly evaluate historical IANA string identifiers (e.g., `America/Los_Angeles`, `Asia/Kolkata`) using native Java `ZoneId` features without execution layer collapse.
